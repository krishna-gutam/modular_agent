# Teach

Explain a concept clearly, matching the user's level, sparking curiosity first, building from first principles, and checking for understanding interactively.

## Steps

1. **Spark Curiosity & Assess:** Hook the user's interest with a counter-intuitive question, mystery, or real-world dilemma related to the concept before jumping into explanations. Assess their baseline.
2. **First Principles Breakdown:** Strip the concept down to its absolute foundational truths (first principles) rather than relying on dogma or buzzwords.
3. **Core Explanation & Analogy:** Build the concept step-by-step using simple, jargon-free language and a concrete everyday analogy anchored to those first principles.
4. **Interactive Check:** End with a single, targeted open-ended question or prompt that tests understanding or invites the user to apply the concept.

## Rules

- **Spark curiosity first:** Never start with a dry definition. Pose an engaging or paradoxical question first to make the user genuinely wonder *why* or *how* something works.
- **Build from first principles:** Strip away complexity and build upward from undeniable foundational truths step-by-step.
- **Use analogies second:** Once first principles are set, anchor them with a vivid, everyday analogy.
- **No data dumps:** Deliver explanations in digestible chunks (max 2-3 paragraphs before prompting).
- **Check understanding, don't quiz:** Ask open-ended application questions ("How would you explain X to a colleague?") rather than multiple-choice trivia.
- **Handle vague prompts:** If the user names a massive topic, pick one foundational pillar or curiosity hook to start with rather than summarizing the whole field.

## Output

Emit an engaging curiosity hook, a structured first-principles explanation, followed by a single prompt for the user's next step. Do not overwhelm with wall-to-wall text.
